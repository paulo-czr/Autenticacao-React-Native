## Sobre o projeto

Projeto desenvolvido com o objetivo de estudar e compreender a estrutura de autenticação em aplicações React Native, utilizando TypeScript, Expo Router e persistência de dados com AsyncStorage.

A proposta é entender, na prática, como organizar um fluxo de autenticação, controlar o estado do usuário e proteger o acesso às telas da aplicação.

## Objetivo

Este projeto faz parte dos meus estudos de desenvolvimento mobile com React Native. O foco principal é compreender e praticar conceitos como:

- Autenticação de usuários
- Login e logout
- Controle e persistência de sessão
- Persistência de dados com `AsyncStorage`
- Gerenciamento do estado de autenticação
- Proteção de rotas
- Navegação condicional entre telas
- Organização de uma estrutura de autenticação

## Tecnologias

| Tecnologia | Descrição |
|---|---|
| React Native | Framework para desenvolvimento mobile multiplataforma |
| Expo | Ferramentas e serviços para apps React Native |
| Expo Router | Roteamento baseado em arquivos |
| TypeScript | Superset tipado do JavaScript |
| AsyncStorage | Armazenamento local persistente |

## Executando o projeto

```bash
# Instalar as dependências
npm install

# Iniciar o projeto
npx expo start
```
